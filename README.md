# Data-Structure

**C 언어로 자료구조의 동작 원리를 익히는 학습 저장소**

구조체, 포인터, 동적 메모리 할당을 활용해 자료구조를 직접 구현합니다. 현재는 정수를 저장하는 단일 연결 리스트 예제가 포함되어 있습니다.

## 구현 내용

### 단일 연결 리스트 — `LinkedList.c`

각 노드는 정수 데이터와 다음 노드의 주소를 저장합니다.

```c
typedef struct ListNode
{
    int num;
    struct ListNode* next;
} LIST;
```

콘솔 메뉴에서 데이터를 추가하거나 출력하고, 마지막 데이터를 삭제하거나 데이터 개수를 확인할 수 있습니다.

| 메뉴 | 기능 | 관련 함수 |
| --- | --- | --- |
| `1` | 리스트 끝에 정수 추가 | `Add_Rear_Num` |
| `2` | 전체 데이터 출력 | `Print_All` |
| `3` | 마지막 데이터 삭제 | `Delete_Rear_Num` |
| `4` | 데이터 개수 확인 | `Count_List` |
| `0` | 프로그램 종료 | `main` |

## 학습 포인트

- 자기 참조 구조체로 노드 정의하기
- 포인터를 따라 연결 리스트 순회하기
- 마지막 노드에 새 노드 연결하기
- 노드 삭제 시 연결 관계 변경하기
- `malloc`과 `free`를 이용한 동적 메모리 관리
- 빈 리스트와 단일 노드 리스트의 예외 상황 처리하기

## 실행 방법

```bash
git clone https://github.com/leetk321/Data-Structure.git
cd Data-Structure
```

### GCC

```bash
gcc LinkedList.c -o linkedlist
```

Linux에서는 `./linkedlist`, Windows PowerShell에서는 `.\linkedlist.exe`로 실행합니다.

### Visual Studio

C 콘솔 프로젝트를 만들고 `LinkedList.c`를 추가한 뒤 빌드합니다. 파일을 C 소스로 컴파일하도록 설정합니다.

## 사용 흐름

1. `1`을 선택하고 `10`을 입력합니다.
2. 다시 `1`을 선택하고 `20`을 입력합니다.
3. `2`를 선택하면 `10 20`이 출력됩니다.
4. `4`를 선택하면 데이터 개수 `2`를 확인할 수 있습니다.
5. `3`을 선택하면 마지막 데이터인 `20`이 삭제됩니다.

## 현재 구현의 제한

- 첫 노드의 정수 값을 `NULL`, 즉 `0`과 비교해 빈 리스트를 판단하므로 `0`을 일반 데이터로 저장하는 데 제약이 있습니다.
- 숫자가 아닌 입력과 메모리 할당 실패에 대한 처리가 없습니다.
- 프로그램 종료 시 남아 있는 노드 전체를 해제하는 처리가 없습니다.
- `0`으로 종료할 때도 `default` 분기를 거쳐 잘못된 입력 메시지가 출력됩니다.
- `malloc.h` 사용과 정수·`NULL` 비교 때문에 컴파일러에 따라 경고나 호환성 문제가 발생할 수 있습니다.

학습용 구현으로, 이러한 부분을 개선하며 연결 리스트의 예외 처리와 메모리 관리를 함께 연습할 수 있습니다.
